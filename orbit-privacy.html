Orbit Privacy Policy

Last updated: 2026-10-25

Orbit is a personal assistant built and used only by Oleg Suvorov. It is not offered to the public and has no users other than its owner.

What it accesses

With the owner's Google authorization, Orbit reads the owner's own Gmail messages and Google Calendar events (read-only). It cannot send, delete, or modify email.

How data is used

Data is read on request to answer the owner's questions and is processed by an AI model. It is used for no other purpose: no advertising, no sale, no sharing with third parties, no human review.

Storage

Orbit stores Google OAuth tokens on a private server controlled by the owner. Email content is not copied into public repositories. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

Orbit's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: see the contact links on suvorav.com.
