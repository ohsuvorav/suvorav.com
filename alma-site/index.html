How it works

Raw notes, a wiki, then agents

Notes go in as they are. Checked knowledge and principles live in the wiki. Agents search that wiki and propose updates as pull requests.

One brain for many agents: every agent searches the same memory, and changes come as pull requests you approve.

Capture

raw/

Drop notes in as they are. Meetings, decisions, half-formed thoughts.

Distill

wiki/

Checked knowledge and principles live here. Agents propose changes as pull requests you review.

Use

search

Hybrid semantic and keyword search, over MCP. Claude Code hooks can bring matches into the session.

How it's different

An interface, not my brain

In Java, callers depend on an interface. The class is the implementation, and it stays yours.

Alma is the interface: the folder contract (raw/, wiki/), teambrain.yaml, the brain commands, the hooks, and MCP search. Your brain is the class: your config and your content.

  • Your content stays in your own git repo.
  • Agents propose changes as pull requests you review.
  • Plain markdown, no lock-in.

Commands

One line each

Command What it does
brain init Create a brain and ask which sources to import.
brain doctor Check the setup. For each problem, one line on how to fix it.
brain index Rebuild the search index from the markdown in this brain.
brain query Search the brain and print the matches.
brain retro Review recent agent sessions and propose updates.
brain lint Report stale docs, idle folders, duplicates, and broken links. Read-only.
brain review Show one stale or disputed item at a time: keep, fix, or archive. Never a wall.
brain snapshot Save local-only history for a working folder the brain's git ignores.
brain schedule Run a brain command on a timer.
brain onboard Connect an agent in this folder so it can search the brain.
brain wip List notes and proposals still outside the wiki.
brain suggest Draft a proposed update for you to review.

Quickstart

From clone to first answer on your own notes in under 10 minutes.

Terminal

git clone https://github.com/ohsuvorav/alma-brain.git
cd alma-brain
brain setup
brain init my-brain
brain doctor
# Ask your agent a question.
# It answers from your notes, with a link to the source.

brain init asks which sources to import: a markdown or Obsidian folder, Notion or Google Docs via MCP, or Claude memory and chat exports.
